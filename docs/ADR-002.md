# ADR-002: Add comparison alongside the preserved original workflow

## Context

Activity 4 requires country A/B and inclusive start/end years; count, total and average
hours for each; greater-total country or tie; zero count/total and unavailable average
for no matches; controlled invalid ranges and unknown countries. Existing functionality
must continue. The verification slide calls this FR22.

## Alternatives

1. Replace the original interaction with a menu or new application: unnecessary change
   to the inherited workflow; rejected.
2. Add arithmetic and display inside evacodev2.py: leaves the new operation mixed and
   difficult to test independently; rejected.
3. Add a pure comparison in the existing analysis module, reuse the inherited country
   sum, add a presentation function and optional CLI flags: chosen.
4. New records/classes/query framework: not needed; keep inherited tuples and ordinary
   result dictionaries with documented keys.

## Decision

No arguments execute the original country query/graph sequence. Optional `--compare A B
--start-year Y --end-year Y` selects text comparison without prompting/plotting.
compare_countries validates input, filters years, creates two dictionaries and selects
winner/tie. _country_summary calls the unmodified total_duration_for_country and derives
count/mean. display_comparison handles output. No loading or preparation changes.

Known countries come from all prepared records before period filtering, so a known
country with no matches differs from an unknown label. Case/outer whitespace in new
comparison input is normalised. Years must be integers in 1..9999 with start <= end;
equal years are allowed. Empty selection has average None and displays unavailable.
Same-country comparison is permitted and ties. An empty prepared dataset has no known
country labels. Totals use the original float hours; equality uses an absolute 1e-9 hour
tolerance (no relative tolerance), below source minute precision, to ignore addition noise.
Ranking happens before display rounding. Dated zero-duration entries count; missing
date/duration entries remain excluded as originally. This describes dataset entries,
not certified counts of completed EVAs. Invalid comparison input prints a message and
returns exit 2; argparse handles invalid option syntax/nonnumeric years similarly.

## Rationale

Only analysis, presentation and the original coordinator need extension. The original
preparation, cumulative loop, country sum, prompt and text/plot statements remain intact.
No alternative representation, new dependency or unrelated feature is introduced.

## Consequences

A few scans are simple and proportionate for 330 records; reuse avoids a second
interpretation of duration or missing data. Dictionaries and tuples need documented
keys/positions. Float tolerance requires explanation; integer-minute migration could
be considered separately. Existing malformed-data behaviour remains a known limitation
rather than being silently tightened during extraction.
